QUICK API REFERENCE:
--------------------
Get Student Analytics:
  const analytics = await getStudentAnalytics(userId, classId)
  → StudentAnalytics {
      totalQuizzes, averageScore, highestScore,
      topicsCompleted, currentStreak,
      engagementScore, lastActiveDate, ...
    }

Get Class Analytics:
  const metrics = await getClassAnalytics(classId)
  → ClassAnalytics {
      averageScore, completionRate,
      topPerformers[], needsSupport[],
      commonWeakTopics[], ...
    }

Get Performance Trend:
  const trend = await getPerformanceTrend(userId, classId, 30)
  → PerformanceTrend[] {
      date, score, attemptCount
    }

Export to CSV:
  const csv = exportStudentAnalyticsCSV(analytics)
  downloadFile(csv, 'analytics.csv', 'text/csv')

Export to HTML:
  const html = generateStudentReportHTML(name, analytics, attempts)
  downloadFile(html, 'report.html', 'text/html')

DATABASE STRUCTURE:
-------------------
Required: quiz_attempts collection
  ├─ userId
  ├─ classId
  ├─ quizId
  ├─ scorePercent
  ├─ timeSpent
  ├─ timestamp
  └─ attemptNumber

Optional: quiz_analytics collection
  ├─ questionId
  ├─ correct
  ├─ difficulty
  └─ timeSpent

FIRESTORE INDEXES:
------------------
Create these in Firebase Console:
  • quiz_attempts: userId + classId + timestamp
  • quiz_attempts: classId + timestamp
