🚀 SETUP IN 5 MINUTES:
-----------------------
1. Get API Key:
   → Go to https://console.anthropic.com/api/keys
   → Create new API key
   → Copy key

2. Add to .env.local:
   NEXT_PUBLIC_ANTHROPIC_API_KEY=sk-ant-xxxxx

3. Copy Files:
   lib__ai-service.ts → src/lib/ai-service.ts
   lib__explanation-service.ts → src/lib/explanation-service.ts
   lib__qa-service.ts → src/lib/qa-service.ts
   lib__path-service.ts → src/lib/path-service.ts
   components__ExplanationCard.tsx → src/components/ExplanationCard.tsx
   components__QAInterface.tsx → src/components/QAInterface.tsx

4. Install:
   npm install @anthropic-ai/sdk

5. Create Routes:
   app/topics/[id]/explain/page.tsx
   app/ask-ai/page.tsx
   app/my-learning/page.tsx

6. Add Nav Links:
   /ask-ai → ✨ Ask AI
   /my-learning → 📚 My Learning

TROUBLESHOOTING:
----------------
API Key Error?
  → Check .env.local has correct key
  → Verify key at console.anthropic.com
  → Ensure API is enabled

No Explanations?
  → Check browser console for errors
  → Verify topic content is passed
  → Test with different topic

Streaming Not Working?
  → Check browser supports ReadableStream
  → Verify network connection
  → Try different browser

Rate Limit Hit?
  → Free tier: 10 questions/day
  → Upgrade to Pro tier
  → Wait until next day

RATE LIMITING:
--------------
Free Tier: 10 requests/day
Pro Tier: 100 requests/day

Daily limit resets at UTC midnight
Check remaining with: checkRateLimit(userId)
Record usage with: recordAPIUsage()

API MODELS:
-----------
Current: Claude 3.5 Sonnet
  - Fast, capable, cost-effective
  - Great for education context
  - ~100K token context window

Alternative: Claude 3 Opus
  - More powerful, slower
  - For complex explanations
  - Higher cost

Choose model in lib/ai-service.ts
