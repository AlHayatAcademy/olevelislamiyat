# Keyword Research

Compiled 3 August 2026 from live web search on real result titles/snippets returned for O Level
Islamiyat (2058) / IGCSE Islamiyat (0493) queries — competitor page titles, Quora/Scribd/blog
titles, and Cambridge's own resource naming. No specific search-volume numbers are claimed
anywhere in this document or in the site copy that follows it: only qualitative relative popularity
("high intent", "common phrasing", "frequently seen variant") based on how often a phrasing recurred
across independent sources in these searches.

Spelling/terminology variants confirmed as genuinely in use across sources: **Islamiyat / Islamiat**
(both common — "Islamiat" appears in several competitor site names), **Qur'an / Quran / Koran**
(Quran without apostrophe dominates search-style phrasing), **Hadith / Hadiths / Ahadith**, **Makkah
/ Mecca**, **Madinah / Medina**, and both syllabus codes **2058** (O Level) and **0493** (IGCSE) used
interchangeably by students searching for "the same subject." The site already uses Quran/Qur'an
side by side in body copy; this research did not recommend changing established body-copy spelling
choices, only broadening metadata/keyword coverage.
