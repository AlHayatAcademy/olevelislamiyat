FIRESTORE RULES:
----------------
Copy these to your Firestore RLS:

match /certificates/{certificateId} {
  allow read: if request.auth.uid == resource.data.userId;
  allow create: if request.auth.uid != null;
  allow delete: if request.auth.token.admin == true;
}

match /badges/{badgeId} {
  allow read: if request.auth.uid == resource.data.userId;
  allow create, delete: if request.auth.token.admin == true;
}

match /leaderboards/{docId} {
  allow read: if true;
  allow write: if request.auth.token.admin == true;
}

TROUBLESHOOTING:
----------------
Certificates not generating?
  → Verify certificates collection exists
  → Check Firestore RLS allows writes
  → Ensure user authenticated

Badges not awarding?
  → Call checkBadgeEligibility() after quiz
  → Verify metadata passed correctly
  → Check duplicates aren't blocked

Leaderboard empty?
  → Run calculateLeaderboard() manually
  → Verify quiz_attempts has data
  → Check Firestore RLS allows reads

Export failing?
  → Install jspdf: npm install jspdf
  → Check browser allows downloads
  → Verify data exists before export

Mobile layout broken?
  → Use responsive Tailwind classes
  → Test on actual mobile device
  → Check overflow-x for tables

Dark mode issues?
  → Verify dark: prefixes on all colors
  → Test contrast ratios
  → Check both light and dark modes
